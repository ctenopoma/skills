# 手法の選定フロー(stats-mcp との対応)

「問い」から手法を選ぶ。手法名から入らない。

## 問い → 手法

| 問い | 手法 | stats-mcp ツール |
| --- | --- | --- |
| 2群で平均に差があるか | Welch の t 検定 | `compare_groups`(2群なら自動で t 検定) |
| 3群以上で平均に差があるか | 一元配置 ANOVA | `compare_groups`(3群以上なら自動で ANOVA) |
| カテゴリ A と B に関連があるか | カイ二乗検定 | `test_independence` |
| 数値同士の関係の強さ | 相関係数 | `correlation`(直線的なら pearson、単調なら spearman) |
| この列は正規分布とみなせるか | Shapiro-Wilk 検定 | `check_normality`(パラメトリック検定の下調べ) |
| そもそも予測できそうか / 効く変数はどれか | ベースラインモデル | `quick_fit`(RandomForest + 5-fold CV) |

## 判断の注意

- **先に下調べ**: 平均差の検定の前に、分布の形(`check_normality`・ヒストグラム)と
  群ごとの n を見る。ひどく歪んでいる・n が小さい場合はその旨を報告に含める
- **p 値の扱い**: p < 0.05 を機械的に「差がある」と言い切らない。効果の大きさ
  (平均差そのもの)と実務上の意味を併記する。検定を何度も繰り返すときは
  多重比較の問題に言及する
- **ANOVA の後**: 「どの群間に差があるか」までは自動では分からない。必要なら
  群のペアごとに `compare_groups` を行い、多重比較である旨を注記する
- **quick_fit の位置づけ**: 「予測できそうか」「どの変数が効いていそうか」の
  当たり付けまで。CV スコアが低ければ「この特徴量では予測が難しい」という
  それ自体有用な発見。本格的なモデリング(特徴量設計・パラメータ調整・
  適切なデータ分割)は別の仕事として提案する
- **サンプルサイズ**: 群あたり n < 20 程度なら検定結果は参考程度と明記する
