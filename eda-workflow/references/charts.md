# 図の選び方(plot-mcp との対応)

「何を伝えたいか」から図を選ぶ。飾りではなく判断の道具として描く。

| 伝えたいこと | 図 | plot-mcp での描き方 |
| --- | --- | --- |
| 1変数の分布・外れ値 | ヒストグラム | `histogram(csv, column)` |
| 2つの数値の関係 | 散布図 | `plot_csv(csv, x, y, kind="scatter")` |
| 時間・順序に沿う変化 | 折れ線 | `plot_csv(csv, x=時間列, y, kind="line")` |
| カテゴリ別の量の比較 | 棒グラフ | `plot_csv(csv, x=カテゴリ, y, kind="bar")`(集計は先に data-mcp で) |
| カテゴリ別の分布比較 | 群別ヒストグラム | グループごとに export → histogram(箱ひげ図は改造課題) |

## 作法

- 比較の棒グラフは軸をゼロから始める(途中から始めると差が誇張される)
- 桁が大きく違うデータは対数軸を検討する(その旨を必ず注記)
- ヒストグラムのビン数で印象が変わる。判断が割れたらビン数を変えて2枚見る
- 円グラフは使わない(比較に向かない)。構成比も棒で
- 1枚の図で言いたいことは1つ。複数の主張は図を分ける

## 描く順番の目安(全体把握モード)

1. 目的変数(あれば)の分布
2. 主要な数値列の分布(全列やらない。profile を見て面白そうな列に絞る)
3. 相関の強い組み合わせの散布図(相関行列で当たりを付けてから)
4. 時間列があれば主要指標の推移
