# diagram: ポンチ絵・概念図を作る

「描画ツールでマウス作業」を「テキストで記述」に置き換える。
修正・バージョン管理・流用が楽になる。

## 手順

1. **図種を決める**: references/types.md の対応表(伝えたいこと → 図種)で選ぶ
2. **出力形式を決める**:
   - Markdown 文書・GitHub・社内 Wiki に載せる → **Mermaid**(references/mermaid.md)
   - 単体ファイルで渡す・html-craft の成果物に埋め込む・見た目を細かく調整したい
     → **SVG 直書き**(references/svg.md)
   - 迷ったら Mermaid(記述が短く、修正が楽)
3. **要素の洗い出し**: 描き始める前に、登場する箱(要素)と矢印(関係)を
   箇条書きで提示してユーザーと合意する。ここで合意すると手戻りがない
4. **描く**: 該当 references の記法パターンに従って書く
5. **確認**: Mermaid は対応ビューア(GitHub 等)での表示を案内。
   SVG はブラウザで開いて自分で確認してから渡す

## ルール

- 1枚に詰め込みすぎない。**箱は7個前後まで**。超えるなら図を分けるか階層化する
- 線の交差を減らす配置を優先する(流れは左→右 か 上→下 のどちらかに統一)
- 色は意味があるときだけ使う(強調1色+補助1色まで)。装飾に使わない
- ラベルは名詞または「動詞+目的語」で短く。文章を箱に入れない
- 図の下に1行のキャプション(この図が言いたいこと)を添える
