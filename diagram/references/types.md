# 図種の選び方

「伝えたいこと」から選ぶ。見た目の好みから入らない。

| 伝えたいこと | 図種 | Mermaid 記法 |
| --- | --- | --- |
| 処理・作業の流れ(分岐あり) | フローチャート | `flowchart` |
| 登場者間の時系列のやり取り | シーケンス図 | `sequenceDiagram` |
| システム・組織の構成(包含関係) | ブロック図 | `flowchart` + `subgraph` |
| 状態の遷移(モード・ステータス) | 状態遷移図 | `stateDiagram-v2` |
| 原因と結果のつながり | 因果図(有向グラフ) | `flowchart`(矢印=影響の向き) |
| 実験・測定の手順と分岐 | 手順フロー | `flowchart TD` |
| 日程・工程の重なり | ガントチャート | `gantt` |
| 概念の分類・階層 | ツリー | `flowchart TD`(枝分かれ) |

## 迷いやすいケース

- 「流れ」か「構成」か: 時間・順序があるならフローチャート、
  ないなら(部品の配置・所属なら)ブロック図
- 「フロー」か「シーケンス」か: 登場者が1人ならフロー、
  複数の登場者の間を行き来するならシーケンス
- 因果図で矢印が双方向になりそうなとき: ループ(フィードバック)として
  明示的に描く。両矢印は避ける(どちらが原因か曖昧になる)
