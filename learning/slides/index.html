ハンズオン教材

MCP & Skills 学習カリキュラム

Agent Skills と MCP サーバの「使い方 → 作り方 → 連携」を
Claude Code を題材に、動かしながら学ぶ。

この教材の使い方

  • 各章の HTML をブラウザで直接開くだけ。サーバも外部通信も不要
  • 紙芝居形式: → / ← キー、または画面下のボタンでめくる
  • 右上の「一覧表示」で全ページを縦に並べて読むこともできる(印刷もこのモードで)
  • 進め方はどの章も同じ: 動かす → 中身を読む → 自分で改造する

レベルA: 基礎(ToDo 題材)

STEP 1

Agent Skills

Skill = Claude への「手順書」。最小の SKILL.md を手で書き、references/ での拡張、OSS スキルの導入まで。

 STEP 2

MCP サーバ

OSS サーバの利用 → Python 50行で ToDo サーバを内製(STDIO)→ 同じコードを HTTP 化。

 STEP 3

Skills × MCP 連携

目標をタスク分解して ToDo MCP に登録する「作業分解プランナー」を作る。連携の正体は SKILL.md にツール名を書くだけ。

レベルB: 中級(入出力をテキスト以外に広げる)

LEVEL B-1

画像を返す MCP

CSV を渡すとグラフを PNG で返す plot-mcp。LLM が描いたグラフを自分で見て考察する。

 LEVEL B-2

ローカル文献ライブラリ MCP

手元の PDF フォルダを全文検索。入力がバイナリのパターンと resources 機能を学ぶ。

レベルC: 上級(本格スキル開発)

LEVEL C-1

html-craft を触りながら学ぶ

スライド/ダッシュボード/デモを作らせ、SKILL.md と scripts を読み、references に自分の部品を足して、自分のスキルの設計図を書く。

 LEVEL C-2

データ分析支援セットを動かす

サンプルデータで分析を一巡→答え合わせ→ログで設計原則を確認→箱ひげ図を道具と手順書にセットで追加する改造まで。

付録

APPENDIX

周辺エコシステム

配布(git/プラグイン/パッケージ/ゲートウェイ)、LiteLLM Proxy と MCP Gateway・Skills Gateway、MCP Inspector。

前提環境

  • Claude Code が動作すること(LLM への API 通信が可能なこと)
  • Python 3.10+ / pip、Node.js / npm、git(GitHub からの clone に使用)
  • 外部 Web API へのアクセスは不要。教材はすべてローカルで完結する

最初にこれだけ: 用語の整理

Agent Skills Claude への「手順書」。SKILL.md という Markdown に、いつ発動するか(description)と何をどの順でやるか(本文)を書く。コード不要
MCP Model Context Protocol。LLM アプリに「道具」を生やす標準プロトコル。MCP サーバがツール(関数)やリソース(データ)を提供し、Claude Code などが呼ぶ
両者の関係 Skill は手順書、MCP は道具箱。道具の使い方・使う順番を手順書に書くと連携する(→ Step 3)
