# コミットメッセージ作成

## 手順

1. `git diff --staged` でステージ済みの変更を確認する。何もステージされていなければ
   `git status` を見せて、どの変更をコミットするかユーザーに確認する
2. 変更内容から type を選ぶ:
   - `feat`: 機能追加
   - `fix`: バグ修正
   - `docs`: ドキュメントのみの変更
   - `refactor`: 挙動を変えないコード整理
   - `test`: テストの追加・修正
   - `chore`: ビルド・設定などその他
3. 次の形式でメッセージを作る:

   ```
   <type>: <変更の要約(50文字以内、言い切り形)>

   <必要なら本文: なぜこの変更をしたか>
   ```

## ルール

- 要約は「何をしたか」ではなく「この変更で何がどうなるか」を書く
- 複数の無関係な変更が混ざっていたら、コミットを分けることを提案する
- メッセージはユーザーの使用言語に合わせる
