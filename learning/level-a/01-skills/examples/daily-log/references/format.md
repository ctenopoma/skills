# 作業ログのテンプレート

新規ファイル作成時は以下の構成で始める。追記時は該当セクションに足す。

```markdown
# 2026-07-22 (火)

## やったこと

- [プロジェクト名 or 分類] 内容。結果や成果物があれば併記
- ...

## メモ・気づき

- 詰まった点、学んだこと、共有事項など(なければセクションごと省略)

## 明日やること

- (任意。ユーザーが言及したときだけ書く)
```

## 記載ルール

- 「やったこと」は1項目1行。先頭に `[分類]` を付ける(例: `[skills]`, `[会議]`, `[調査]`)
- 事実と所感を混ぜない。所感は「メモ・気づき」へ
- 時刻は書かない(日単位の粒度で十分)
