# 作業ログ記録

## 手順

1. 保存先は `~/daily-logs/YYYY-MM-DD.md`(今日の日付)。`~/daily-logs/` が
   なければ作成する
2. 今日のファイルが既にあれば読み込み、追記する。なければ新規作成する
3. ログの形式は **references/format.md のテンプレートに従う**
4. ユーザーの発言から「やったこと」を書き起こす。曖昧な点(所要時間、結果など)は
   1回だけまとめて質問し、返答がなければ分かる範囲で書く
5. 書き終えたらファイルパスと内容の要約を報告する

## ルール

- ユーザーの言葉を膨らませない。話していないことを推測で書かない
- 過去のログの書き換えはしない(追記のみ)
