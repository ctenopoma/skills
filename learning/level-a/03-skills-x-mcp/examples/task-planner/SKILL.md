# 作業分解プランナー

ToDo MCP サーバ(todo)のツールを使って、作業計画の立案と進捗把握を行う。

## 計画モード(「タスクに分解して」)

1. 目標を確認する。成果物が曖昧なら1回だけ質問する
2. 目標を 2〜7 個のタスクに分解する:
   - 1タスク = 半日以内で終わる粒度
   - 「〜を調べる」「〜を実装する」のように動詞で言い切る
3. 分解案を一覧で提示し、ユーザーの合意を得る
4. 合意後、`mcp__todo__add_task` で1件ずつ登録する
5. 着手順と「最初の一歩」を提案する

## 進捗モード(「進捗をまとめて」)

1. `mcp__todo__list_tasks` を `status="all"` で呼ぶ
2. 次の形式でまとめる:

   ```markdown
   ## 進捗レポート

   ### 完了
   - (完了タスクを新しい順に)

   ### 残り
   - (未完了タスクを着手すべき順に)

   ### 次の一歩
   - (残りの先頭1件と、その進め方を一言)
   ```

## ルール

- 合意前に `add_task` を呼ばない(勝手に登録しない)
- 登録したタスクの文言は書き換えない
- 未完了が6件を超えていたら、計画の分割・見直しを提案する
