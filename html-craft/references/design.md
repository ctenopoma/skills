# 共通デザイン原則(全モード必読)

## 自己完結の鉄則

成果物は**HTMLファイル1個**で完結させる。渡す・置く・開くだけで動くことが価値。

- CSS / JS はすべて `<style>` / `<script>` としてインライン化する(assets/ のファイルは雛形生成時に展開される。手書きするときも同様にインラインで)
- 外部CDN・外部フォント・fetch/XHR は**禁止**(オフライン・プロキシ環境で開けなくなる)
- 画像は base64 の data URI で埋め込む(`<img src="data:image/png;base64,...">`)。
  Python での変換: `base64.b64encode(Path(p).read_bytes()).decode()`
- データは `<script>const DATA = [...]</script>` として埋め込む

## タイポグラフィ

- フォントはシステムフォントスタック:
  `"Hiragino Sans", "Yu Gothic UI", "Meiryo", "Segoe UI", sans-serif`
- 日本語本文は `line-height: 1.8` 前後。詰まった行間は可読性を大きく落とす
- 本文 16〜18px。スライドは大きめ(本文18px、見出し27px以上)
- 等幅は `Consolas, "Courier New", monospace`

## 配色

CSSカスタムプロパティで一元管理する(assets の `--ink` `--accent` などを使う)。

- 基本はインク色(#1e293b)+アクセント1色(#4f46e5)+背景(#eef2f7)
- 意味色は固定: 緑=良い/完了、赤=悪い/エラー、琥珀=注意、青=情報
- 色だけに意味を持たせない(ラベルや形も併用)

## レイアウト

- コンテンツ幅は最大 920〜1080px、中央寄せ
- カード(白背景+角丸+薄い影)を情報のまとまりの単位にする
- 余白をけちらない。詰め込むより枚数・カード数を増やす

## 印刷・PDF

- `@media print` を整える(ナビ・コントロール類は非表示、背景は白)
- PDF化は `scripts/to_pdf.py`(Edge ヘッドレス印刷)

## 検証

書いたら必ずブラウザで開いて確認する。特に:

- 横スクロールが出ていないか(はみ出し)
- 長いコード・表が枠内でスクロールできるか
- 拡大縮小(Ctrl+±)で崩れないか
