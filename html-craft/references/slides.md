# slides モード: 紙芝居スライドの設計

雛形: `python scripts/new_page.py slides 出力.html --title "..."`
(assets/deck.css と deck.js がインライン展開される)

## 構成の型

1. **表紙**: タイトル+リード文1〜2行+操作ヒント(`.title-slide`)
2. **結論・全体像を先に**: 2〜3枚目までに「何の話でどこに着地するか」
3. **本論**: 1枚1メッセージで積む
4. **まとめ**: 学び・依頼事項・次のアクション

枚数の目安: 5分の説明で5〜8枚、30分の発表で15〜25枚。迷ったら減らす。

## 1枚1メッセージ

- スライドタイトル(h2)は「見出し」ではなく**言いたいことの要約文**にする
  - 悪い例: 「実験結果」 / 良い例: 「条件Bだけ応答が2倍速い」
- 1枚に入れる要素は「主張+根拠1つ」まで。溢れたら分割する
- 口頭で補う前提の資料なら文字を減らす。読み物として配るなら文章で書く

## 使える部品(deck.css に定義済み)

| 部品 | クラス | 用途 |
| --- | --- | --- |
| コールアウト | `.note` `.warn` `.point` | 補足・注意・要点の強調 |
| ボックス+矢印の図 | `.flow` > `.box` / `.arrow` | 構成図・手順・因果 |
| ファイルツリー | `.tree` | ディレクトリ構成 |
| コード | `pre > code`(`.filename` でファイル名) | コード・コマンド |
| チップ | `.chip` | セクションラベル |
| 強調 | `em`(蛍光マーカー風)/ `strong` | キーワード |

- 表は5行まで。それ以上は「代表行だけ見せて詳細は配布資料へ」
- 図版(グラフ画像)は base64 埋め込み。`max-width:100%` を忘れない

## ナビゲーション仕様(deck.js)

- `←`/`→`/`Space`/`PageUp/Down`/`Home`/`End`、画面下のボタン
- URLハッシュ `#5` で途中ページを直接開ける
- 「一覧表示」ボタンで全スライド縦並び(そのまま印刷・PDF化に使う)
- 発表時はブラウザのフルスクリーン(F11)

## 大型デッキの分担執筆(マルチエージェント)

15枚を超える資料は、一人で頭から書くより分担が速く品質も揃う:

1. 親: アウトライン(章立てと各章の主張)を先に確定し、ユーザーと合意する
2. 親→サブエージェント: 章ごとに「主張・材料・トーン・使ってよい部品」を指示して
   `<section class="slide">...</section>` 断片を並列で書かせる
3. 親: 断片を結合し、**用語・デザイン・粒度の一貫性を親が最終責任で揃える**
   (重複の削除、リズムの調整、枚数の刈り込み)

サブエージェントへの指示に「1枚1メッセージ」「タイトルは要約文」のルールを毎回含めること。
