# html-craft: 自己完結HTMLの成果物を作る

PowerPoint・Excel共有・口頭説明を、ブラウザで直接開ける HTML 1ファイルに置き換える。
サーバ不要、外部通信なし、渡すだけで動く。

## 手順

1. **モードを判定する**。曖昧なら1回だけ確認する

   | ユーザーの意図 | モード | 必読 |
   | --- | --- | --- |
   | 発表・報告・説明資料(ページをめくる) | slides | references/slides.md |
   | データを眺める・共有する(フィルタ・表・グラフ) | dashboard | references/dashboard.md |
   | 原理・挙動を触って見せる(パラメータで変わる) | demo | references/demo.md |

2. **references/design.md(共通原則)と、モードの references を読む**
3. **雛形を生成する**:

   ```
   python scripts/new_page.py <mode> <出力.html> --title "<タイトル>"
   ```

   assets/ の CSS・JS がインライン展開された自己完結ファイルができる。
   雛形を使わず直接書いてもよいが、その場合も assets の CSS/JS を
   インラインで埋め込み、必ず1ファイルで完結させる

4. **材料を集めて本文を書く**。画像は base64 埋め込み、データは `const DATA` 埋め込み
   (詳細は design.md)。MCP ツールで作った画像(グラフ等)もそのまま埋め込める
5. **ブラウザで開いて確認する**。はみ出し・文字化け・操作性をチェック
6. 必要なら PDF 化: `python scripts/to_pdf.py <入力.html> <出力.pdf>`
   (Edge のヘッドレス印刷。追加インストール不要)

## ルール

- 自己完結を絶対に崩さない: CDN・外部フォント・fetch 禁止(オフラインで開けなくなる)
- 生成後に必ず自分でブラウザ確認してから完成を報告する
- 既存ファイルの上書きはユーザーに確認してから
- 大型スライド(15枚超)は references/slides.md の「分担執筆」手順で並列化する
