# テスト方針

- 税率区分 "01"〜"04" ＋ 不正コードで同値分割。金額は 0・最小単位・上限 9(9)V99 で境界値。
- グローバル状態: TAX-RATE-TABLE は fixture で注入。WK-ERR-FLG は事後検証対象。
- RATEMST.dat は tmp_path に実体生成（SPEC-03 のフォールバック経路用）。
- ROUND-AMT (F-0087) は実装済みのため REAL 呼び出し。
- レガシー実行環境なし。期待値は仕様🟢から導出し、🟡🔴由来はISSUEで人間確認して確定する。
