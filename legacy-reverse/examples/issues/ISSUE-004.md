# 事象

CALC-TAX の端数処理は区分 "01"〜"03" が切り捨てなのに対し、"04" のみ切り上げになっている（`legacy/tax.cbl:180-195`）。コメントも仕様書もなく、意図的か過去の修正ミスか判別できない。

# 質問（人への問い）

**仮説**: 区分 "04" は印紙税相当で、法令上切り上げが正しい——つまりバグではなく正仕様。

**問い**: この理解で正しいですか？（Yes / No / 修正）

# 回答（人が記入）

- 回答: Yes。"04" は印紙税区分で、切り上げが法令要件。バグ互換ではなく正仕様として移植する。
